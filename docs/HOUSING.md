# Система жилья: каморка -> квартира -> дом -> особняк

## Жилья = главы жизни
1. Каморка (студент) - 12 предметов
2. Квартира (ординатор) - 12 предметов, новый стиль
3. Дом (фельдшер в деревне)
4. Особняк (главврач) + предметы искусства (арт-пасс позже)

## Цикл
Победа -> дроп предмета в альбом текущего жилья.
Собрал 12/12 -> ремонт закончен -> охота за ключом:
шанс 25% + 10% за каждую неудачу (pity) с каждой победы.
Ключ -> переезд в следующее жильё, альбом новый (силуэты).
Ключ за реальные деньги - IAP заглушка (позже).

## Дубликаты и монеты
Дубликат = перекрас цвета (реролл варианта) + 2 монеты.
Победа без дропа = +5 монет.
50 монет = купить недостающий стикер (Panini-механика).

## Собака
Появляется после 3 предметов в жилье.
Уход (кормление за монеты) -> +1 подсказка на уровень (позже).

## Визуал
Комната 2D: обои, пол, окно, ковёр. Мебель по слотам с тенями.
Палитра жилья меняется по главам (яркая -> пастель).
